# Fonts

`NotoSansCJKjp-Regular.otf` is Noto Sans CJK JP (the typeface published on Google
Fonts as Noto Sans JP), by Adobe and Google, from https://github.com/notofonts/noto-cjk.
It is licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which
allows bundling it in an app. Its copyright notice and the license are in `OFL.txt`, which
must stay beside the font: this folder is copied into the app as is, so the license ships
with it. The app uses it for all text; see `Typography.swift`.
